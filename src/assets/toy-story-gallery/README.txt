Poné acá las imágenes para la galería de Toy Story (drawer que se abre
desde el reproductor de ese grupo).

- Cualquier nombre de archivo sirve, no hay que tocar código.
- Formatos aceptados: .png .jpg .jpeg .webp .avif
- Se muestran en orden alfabético del nombre de archivo, una debajo de
  otra (galería vertical). Si querés un orden puntual, prefijalas con
  números: 01-woody.jpg, 02-buzz.jpg, etc.
- Conviene que sean mas o menos parecidas en proporcion (ej. todas
  cuadradas o todas 4:3) para que la galeria se vea pareja.

Después de agregar archivos acá, hay que volver a compilar (vite build)
para que aparezcan.
